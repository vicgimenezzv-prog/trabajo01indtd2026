CAMBIO REALIZADO PARA PODER REALIZAR EL TERCER COMMIT

Este repositorio contiene la resolución individual de dos casos prácticos de decisión bajo incertidumbre:

Problema 1: Análisis de producción para una marca de ropa aplicando los criterios de Wald, Optimista, Hurwicz, Laplace, Savage y Punto Ideal.

Problema 2 (Caso Real): Evaluación de estrategias de ventas de invierno para una heladería aplicando todos los criterios.

El repositorio incluye los códigos fuente en Quarto (.qmd), el script de R con las funciones de cálculo utilizadas y los informes finales exportados en formatos HTML y PDF.
